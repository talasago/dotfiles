# playwright-screenshot

Playwright等のヘッドレスブラウザでアプリのスクリーンショットを撮影する際の共通ルール。

## 撮影前に必ず確認すること

- 撮影対象のページがWebフォント（Google Fonts等の外部フォント）を使っている場合、`document.fonts.ready` を
  待つだけでなく、実際に対象フォントが読み込まれた状態か（`document.fonts.check(...)` 等）を確認する。
  `document.fonts.ready` はフォント読み込みの試行が完了したことしか示さず、読み込みが失敗していても解決する。
- ネットワークログ（`page.on('response')` / `page.on('requestfailed')`）を確認し、フォント・画像等の外部
  リソースへのリクエストが実際に成功しているか確認する。
  - プロキシ経由の実行環境では、TLS証明書検証の問題で外部リソースの取得が失敗することがある。ページの
    見た目は崩れずレンダリングされるため、実際に撮影するまで気づきにくい。
  - リクエストが失敗している場合、TLS検証を無効化するのではなく、正しく証明書検証できる経路（Node.jsの
    `https`モジュール等）で事前にリソースを取得し、Playwrightの`page.route()`でモック返却する。
- 撮影後は必ず生成された画像を目視で確認し、想定通りのフォント・レイアウトになっているかを確認してから
  次の作業に進む。
