# multi-hypothesis-bugfix

バグ報告が原因の仮説を複数挙げている場合、実装した修正がどの仮説に対応するものかを PR 本文に明記する。

検証した他の仮説についても「採用しなかった理由」を明記する。1つの仮説の修正だけで「解決した」と暗黙に扱わず、他の仮説の検討過程を残す。
