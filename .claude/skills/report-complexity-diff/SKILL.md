# report-complexity-diff

対象diffに含まれるロジック変更について、変更前後で時間計算量・空間計算量に変化があるかを確認する。

- 変化がある箇所のみ、変更前後の計算量とその理由を簡潔に報告する
- 計算量に変化がない場合は「計算量に変化なし」とだけ述べる
- 改善案・最適化案は提案しない（報告に留める）
