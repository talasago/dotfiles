# revert-large-diff

実装済みの差分の大部分を取り消すことになった場合、ファイルを1行ずつ Edit で手戻りさせる前に、以下の手順で確認する。

1. `git diff <元ブランチ> -- <file>` で、そのファイルを元ブランチの状態に戻せば差分ゼロにできないか確認する。
2. 差分ゼロ、または差分を最小限に抑えられる場合は `git checkout <元ブランチ> -- <file>` でファイルごと復元する。
3. 無関係な既存バグ修正など、本当に残すべき差分が混在しているファイルのみ手動で編集する。
