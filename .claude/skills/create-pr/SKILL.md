# create-pr

## 手順

1. PRテンプレートを探して読む
   - `.github/PULL_REQUEST_TEMPLATE.md`・`.github/pull_request_template.md`・`docs/`・リポジトリ直下・`.github/PULL_REQUEST_TEMPLATE/` 配下
   - 複数あるときはどれを使うかユーザーに確認する
2. テンプレートの見出し・HTMLコメント・チェックリスト・リンクを残したまま本文を組み立てる。本文の内容はテンプレートの指示に従う
3. チェックボックスは、差分から事実として判断できるものだけチェックする。リリース日程など判断が必要なものは空欄のまま残し、ユーザーに伝える
4. チェックリストがラベル付与を求めていて該当する場合は、`--label` で付与する
5. ユーザーが自分で書くと言ったセクションは、テンプレートのコメントだけを残して空にする
6. 本文は `/translate-en-with-ja` スキルの形式（英語の本文の下に日本語の原文を折りたたむ）で書く。日英を1行ずつ交互に書く形式にはしない
7. タイトル・本文・ラベル・Draftかどうかをユーザーに示し、承認を得てから `gh pr create --body-file` で作成する
