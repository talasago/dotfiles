# record-learning-gaps

ユーザーが会話の中で分からなかったことを蓄積するためのスキル。

## ログファイル

`~/claude-records/learning-gaps.md`（実行環境のローカル。git 管理下のリポジトリには置かない）。無ければ作成する。

## 手順

1. このセッションのチャットを振り返り、ユーザーが質問した・聞き返した・「分からない」と言ったテーマを洗い出す
2. 候補を番号付きの一覧でチャットに出し、残さないものをユーザーに選んでもらう。この時点ではログに書かない
3. ユーザーが選んだ後、残すテーマを1件ずつ以下の形でログに追記し、追記した内容をチャットにも出す
   - **分からなかったこと**：ユーザーの質問をそのまま引用する。言い換えない
   - **答え**：会話の中で出た結論を1〜2行で書く。会話で結論が出ていなければ「未解決」と書く
   - **根拠**：答えの根拠にしたファイルパス・URL。無ければ「なし」

```markdown
## YYYY-MM-DD リポジトリ名
- テーマ：〇〇
  - 分からなかったこと：「…」
  - 答え：…
  - 根拠：path/to/file, https://...
```
